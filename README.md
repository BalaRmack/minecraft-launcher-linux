# Horizon

Экспериментальный Minecraft-лаунчер для Linux на Rust, Tauri 2 и SQLite. Интерфейс на русском языке, без Electron. Этот репозиторий **пока не является готовым к выпуску лаунчером**: нативная сборка и запуск игры ещё не прошли сквозную проверку, Flatpak-пакета нет. Не используйте его для единственных копий важных миров.

## Что реализовано в коде

- Локальные офлайн-аккаунты: создание, редактирование, выбор и удаление. Имя ограничено 1–16 латинскими буквами, цифрами и `_`. UUID вычисляется по алгоритму Minecraft OfflinePlayer; при переименовании изменится и UUID персонажа.
- Изолированные сборки с выбором версии release/snapshot из официального манифеста Mojang и загрузчика Vanilla, Fabric, Quilt, Forge или NeoForge. Скачивание и подготовка делегированы `mc-launcher-core` 0.1.2 и выполняются вне потока UI. По завершении профиль помечается установленным; при ошибке повторной установки — нет. Загрузчики и реальные версии игры **не были проверены в этой среде**.
- Офлайн-запуск через указанную Java, настройка предельной памяти, вывод процесса в журнал. Офлайн-аккаунт работает только там, где не требуется официальная онлайн-аутентификация.
- Поиск модов через Modrinth, выбор файла, совместимого с версией и загрузчиком активной установленной сборки, проверка SHA-512, ограничение размера, установка без перезаписи, включение/отключение и удаление файлов модов. Моды с обязательными зависимостями отклоняются: автоматическое разрешение зависимостей пока не реализовано.
- Подтверждение удаления аккаунта, сборки и мода. При удалении сборки удаляются **все** её данные, включая миры.

Профили, моды, миры и настройки хранятся в пользовательском каталоге приложения (`$XDG_DATA_HOME/io.github.balarmack.horizon`, обычно `~/.local/share/io.github.balarmack.horizon`). Каждая сборка имеет собственный каталог `instances/<UUID>` и папку `game`; библиотеки и ресурсы пока также дублируются между сборками. Журнал процесса находится в `game/horizon-game.log`. База данных — `horizon.sqlite3`. Никакие пароли и токены не хранятся, поскольку Microsoft OAuth пока не реализован.

## Существенные ограничения

- Нет готового Flatpak, манифеста Flatpak или проверенной инструкции установки на Bazzite. `.deb`, который пытается собирать CI, не предназначен для установки непосредственно на Fedora Atomic. Не требуется менять или наслаивать RPM на хост Bazzite ради использования этого проекта — но готового способа установки на нём пока нет.
- Java **не загружается автоматически**. Установите совместимую Java отдельно и укажите путь к исполняемому файлу в настройках. Для Forge/NeoForge стороннее ядро запускает установщик через `java` из PATH, а не через путь из настроек.
- Нет Microsoft OAuth, скинов, новостей, импорта/экспорта модпаков, CurseForge, выбора каталога игры, настройки JVM-аргументов, управления кэшем и очистки временных файлов.
- Загрузчик ядра последователен; настройки параллелизма и повторных попыток отсутствуют. Ядро проверяет SHA-1 там, где он предоставлен, но некоторые файлы без контрольной суммы повторно используются по наличию. Процент общего прогресса не вычисляется; отображается текущая задача. Загрузка Modrinth проверяется SHA-512 до записи.
- Эта реализация зависит от стороннего `mc-launcher-core`; заявленная поддержка разных версий и загрузчиков нуждается в интеграционном тестировании на реальном Linux с доступом к сервисам Mojang и Modrinth. Нельзя считать её полноценной заменой зрелому лаунчеру до проверки и исправления обнаруженных проблем.

## Сборка для разработки на обычном Linux x86_64

Нужны свежий стабильный Rust и Cargo, Node.js/npm, системные зависимости Tauri 2 (GTK 3, WebKitGTK 4.1, librsvg, OpenSSL, xz и инструменты C/C++). На Debian/Ubuntu для сборки:

```sh
sudo apt-get update
sudo apt-get install build-essential libwebkit2gtk-4.1-dev libxdo-dev libssl-dev librsvg2-dev liblzma-dev patchelf
npm ci
npm test
cargo test --manifest-path src-tauri/Cargo.toml
npx --yes @tauri-apps/cli@2 dev
# или сборка Debian-пакета
npx --yes @tauri-apps/cli@2 build --bundles deb
```

Сборка не проверялась в текущем окружении: в нём отсутствуют Rust, GTK/WebKit и Flatpak, а доступ к игровым API ограничен. GitHub Actions настроен на тесты и сборку `.deb` как артефакта, но его успешное выполнение ещё необходимо проверить. `npm test` запускает тесты интерфейса с мокированным Tauri IPC; это не интеграционные тесты скачивания и запуска Minecraft.

## Bazzite / Flatpak

Bazzite — целевая платформа, но Flatpak ещё не подготовлен и готового устанавливаемого пакета пока нет. Для безопасного выпуска нужны проверенный Flatpak-манифест с офлайн-сборкой Rust-зависимостей, подходящим runtime/SDK и Java, разрешения графики/аудио/сети, проверка порталов и тестирование установки и реального запуска игры в песочнице. До этого не следует считать инструкции по запуску или сборке на Bazzite завершёнными.

Minecraft является товарным знаком Mojang Studios. Horizon не является официальным продуктом Minecraft.
