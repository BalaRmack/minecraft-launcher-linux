MINECRAFT LAUNCHER
О HORIZON.
Пространство для ваших приключений.
Сделано для игры.
Horizon — экспериментальный лаунчер на Rust и Tauri для Linux. Minecraft не связан с этим проектом и является товарным знаком Mojang Studios.
Текущая версия находится в разработке: аккаунты Microsoft и импорт модпаков ещё не готовы.
